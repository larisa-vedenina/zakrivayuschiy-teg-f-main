# Закрывающий тег - Дневник обучения

Интерактивный дневник с воспоминаниями о процессе обучения фронтенд-разработке. Проект демонстрирует современные возможности CSS и JavaScript.

## Демо

[Открыть проект](https://larisa-vedenina.github.io/zakrivayuschiy-teg-f-main/)

## Особенности

- **Интерактивные карточки** с анимированными лайками
- **CSS фильтры** для создания уникальных визуальных эффектов
- **Темная/светлая тема** с автоматическим определением системных предпочтений
- **Адаптивный дизайн** для всех устройств
- **Семантическая верстка** с поддержкой accessibility
- **Оптимизированная производительность** - lazy loading, эффективные анимации

## Технологии

- **HTML5** - семантическая разметка, dialog элемент
- **CSS3** - Grid, Flexbox, CSS Filters, CSS Variables, Media Queries
- **Vanilla JavaScript** - управление темами, анимации, взаимодействие
- **SVG** - векторная графика и анимации

## Ключевые возможности

### Визуальные эффекты
- 7 различных CSS фильтров для изображений
- Анимированные сердца с состоянием "лайк"
- Плавные переходы между темами

### Accessibility
- Поддержка скринридеров
- Правильная семантика ARIA
- Управление с клавиатуры
- Поддержка prefers-reduced-motion

### Производительность
- Оптимизированные CSS-стили
- Lazy loading изображений
- Эффективные анимации с transform

## Установка и запуск

1. Клонируйте репозиторий:

git clone https://github.com/larisa-vedenina/zakrivayuschiy-teg-f-main.git

2. Откройте index.html в браузере или используйте Live Server:

npx live-server
